# Retail-Microservices-Platform-DevOps-GitOps-on-AWS-EKS-
Retail Microservices Platform – DevOps &amp; GitOps on AWS EKS is a cloud-native retail application built using microservices and deployed on Amazon EKS. The project uses Docker and Kubernetes for orchestration, Terraform for infrastructure provisioning, and GitOps with ArgoCD to automate reliable, scalable deployments.
